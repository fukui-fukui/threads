# 来週末の福井おでかけ3選リール

代表 2026-10-17「イベント3選のリール作成投稿のチームを作って、必要ならスキルで登録しておいて。」
担当は【制作部】イベント3選リール。報告・相談は【統括】へ。投稿はおでかけ開発の仕組み（posts/queue.jsonl・posts/ig-queue.jsonl）で出す。

## 作り方（代表 10/21）

代表 10/21「runwayはコスパ悪いので、しばらくは、gemini　→　google vids　→ claudecodeで編集 でいきましょう。」

1. **制作部**：Gemini 用の画像プロンプトと、Google Vids 用の指示を代表に出す
2. **代表**：Gemini で画像を作り、Google Vids で動画にする（Gemini も Vids も画面の操作は代表。制作部のセッションからは代表の Google アカウントを操作できない）
3. **制作部**：受け取った動画を Claude Code（scripts/リール.py）で編集する（テロップ・尺・縦横・音）→ 代表の OK → おでかけ開発に渡して予約

**Runway は使わない**（クレジットは残しておく）。

## 決まり（必ず守る）

- **代表の OK が出るまで投稿しない**（代表 10/17「OK出すまで、投稿しないこと」）。動画2本とキャプションを見せて OK をもらう。
- **代表の許可は統括へ**（代表 10/21：代表の許可（許可の画面・「進めて」・画像や動画の OK）が要るときは、必ず統括へ。何を・なぜ・お金に関わるかを書く）。代表がこのセッションのチャットで直接 OK・直しを出したときは、その言葉をそのまま記録し、統括にも知らせる。
- **書くのは出典にある事実だけ**。日付・場所・時間は、neta/ネタ帳.md とお店・主催者の公式で1つずつ確かめる。食い違ったら公式が正（10/17 の回はネタ帳の行がまちがっていて、鉄道ふくいフェスタの会場を神明駅に直した）。ネタ帳の行も直す。
- 画像・動画は AI のイメージ。どの場面にも「※画像はイメージです」、終わりに「日時・内容は公式の情報をご確認ください」（scripts/リール.py が自動で入れる）。
- お店のロゴ・看板の文字・実在の人の顔は作らない。プロンプトに必ず入れる。
  - 代表が作った画像・動画にこれらが入っていたら、使う前に代表に知らせて決めてもらう（10/21 の回：③の看板の文字は代表「このままでOK」）。
  - Gemini・Vids の動画の右下には、AI で作った目印の小さなマーク（✦）が入る。消さずにそのまま使う（10/21 の回で代表 OK）。
- 鍵・トークン・署名つきの URL は、ログ・リポジトリ・連絡に残さない。
- BGM は公開リポジトリに入れない。

## 毎週の流れ（代表 10/17「はい」、10/21 に作り方を変更）

毎週1本。投稿は、対象の週末（土日）の1週間前の土曜 16:00。

| 曜日 | やること | だれ |
| --- | --- | --- |
| 月 | 次の次の週末の候補5つを表で出す（朝のネタ集めのあと） | 運用部・福井（制作部が頼む） |
| 火 | 3つ選ぶ → 制作部が公式で確かめ、画像プロンプトと Vids の指示を出す | 代表（統括経由）・制作部 |
| 水 | Gemini で画像3枚 → Vids で動画3本 → 制作部に渡す | 代表 |
| 木 | 編集（テロップ・尺・BGM）→ キャプション → 動画2本とキャプションを見せて OK をもらう（直しはこの日のうちに） | 制作部・代表 |
| 金 | 動画2本を docs/reel に入れる PR を出す → おでかけ開発がマージして予約 | 制作部・おでかけ開発 |
| 土 16:00 | Threads と Instagram に出る | 仕組み |

代表の手間は1週あたり30〜45分ほど（3つ選ぶ5分、画像3枚10〜15分、Vids で動画3本15〜20分、渡す・OK 5分）。

## 手順

### 1. 選ぶ
- 運用部・福井に、来週末（土日）の候補5つを表で出してもらう（名前・イベント期間（開催日と時間）・場所・見どころ・出典 URL）。
- 候補から外すもの（代表 10/19）：
  - **前の回のリールで出したもの**（代表「③はだしたから除外。」）。下の「記録」の表と見比べる
  - **キャラクターの版権がからむもの**（代表「④キャラクター版権的に問題あるから除外。」）。キャラクター展・コラボイベントなど
- 代表に見せるときは、どの候補にも**出典元 URL とイベント期間を一緒に**書く（代表 10/19「出典元URLとイベント期間を一緒に提示するようにお願いします。」）。
- 統括経由で代表が3つ選ぶ。ジャンルと地域が重ならないように。
- 選んだ3つを公式で1つずつ確かめ（WebFetch）、台本.json を書く（下の形）。

### 2. 画像プロンプトを出す（代表が Gemini で作る）
- 1場面ずつ、日本語で出す。代表は Gemini のチャットに、参考写真を添えて貼る。
- **参考写真**：会場の雰囲気がわかる公式の写真（施設・観光協会のページなど）の URL を添える。チラシは文字が多いので使わない。会場の写真がなければ、写真なしで作る。参考写真は参考にするだけで、写真そのものは使わない。
- プロンプトに必ず入れること：
  - 縦長（9:16）の写真風
  - **画面の上 1/3 は空**（テロップをのせる）。料理などの主役は下半分
  - 季節・時間帯（例：秋の晴れた午後）
  - 人を入れるときは、後ろ姿か遠くの人。髪がしっかりある見た目（代表 10/21「頭ハゲている人は作らない」）
  - 文字・看板・のれんの文字・ロゴ・人の顔は入れない
- 例（10/21 の回 ②）：

```
添えた写真の阿納の海の景色をもとに、縦長（9:16）の写真風の画像を作ってください。
小さな漁村の細い路地。両側に古い木造の民家があり、路地の先に添えた写真のような静かな青い海と入り江が見える。
下半分には、路地に並んだ木の台の上に、湯気の立つ漁師鍋、焼き魚、牡蠣、ふぐ料理、パンやコーヒーが並ぶ小さなマルシェ。
秋の昼のやわらかい光。画面の上1/3は空。
人物は入れない。文字・看板・のれんの文字・ロゴ・人の顔は入れない。
```

### 3. Vids の指示を出す（代表が Google Vids で動画にする）
- 代表に渡すもの（場面ごと）：
  - 使う画像（2. で作ったもの）
  - 動きの指示（日本語）。例：「カメラがゆっくり寄る。恐竜が首を振り、トリケラトプスが前へ歩く」「若いカップルが後ろ姿で路地をゆっくり歩き、料理の台を見て回る」「奥のテーブルで両親と3歳くらいの子が座って過ごす。手前の料理はそのまま」
  - 縦長（9:16）を選ぶこと、長さは5秒以上（こちらで5秒を切り出す）
  - 人の顔・看板の文字を新しく足さないこと
- 渡し方：このセッションのチャットに添付してもらう。または Google ドライブの、リンクで共有したフォルダに置いてもらう。
- 10/21 の回で使えたのは、代表の Gemini で作った 1080×1920・約10秒・音つきの動画。Vids で作った動画の大きさ・長さ・目印は、最初の回で確かめてここに書く。
- Vids の AI 動画は、プランごとに月の上限がある（Google AI Pro は月500秒、個人・AI Plus は月60秒）。3選1回で約15〜25秒使う。

### 4. 編集（Claude Code・scripts/リール.py）

```
python scripts/リール.py 作業/台本.json 作業/out --bgm 作業/bgm.mp3
```

- 受け取った動画を、作業フォルダ（スクラッチ）に 1.mp4・2.mp4・3.mp4 として置く。
- まず何コマか切り出して中身を見る（どこから5秒を使うか、文字・顔・看板・目印）：
  `for t in 1 3 5 7 9; do ffmpeg -ss $t -i 2.mp4 -frames:v 1 -vf scale=240:-1 f$t.png; done`
- 台本.json の `start` に使い始めの秒を書く（省略すると頭から5秒）。
- 作業/out/threads.mp4（おわりが @fukui._.fukui）と ig.mp4（@fukui._fukui（プロフィールのリンクから））ができる。どんな大きさの動画でも 720×1280 に切りそろえる。動画の元の音は使わず、BGM だけにする。
- 中身：はじめ 2.5秒（1本目をぼかして「来週末の福井／おでかけ3選／日付」）→ 各5秒×3 → おわり 2.5秒（オレンジの地に「くわしくは ふくいおでかけ で」）。20秒・24fps・720×1280・yuv420p。
- テロップ：上に帯（black@0.45、y=40〜400）。見出し「来週末の福井 おでかけ3選 n/3」（オレンジ 0xE8873A の箱）、イベント名 56px、日にち 40px（黄 0xFFD54F）、場所 34px、見どころ 34px。右下に「※画像はイメージです」。長い文字は横幅に収まるよう自動で小さくなる。フォントは IPAPゴシック（/usr/share/fonts/opentype/ipafont-gothic/ipagp.ttf）。
- BGM：代表のフリーBGM（作者しゃろう。10/17・10/21 は「しゅわしゅわハニーレモン350ml」）。volume 0.8、頭 0.5秒フェードイン、最後 2.5秒フェードアウト。作者名の表記は不要（代表 10/17）。
  - 曲は Google ドライブ AI会社/BGM にある（4曲：しゅわしゅわハニーレモン350ml・極東の羊、テレキャスターと踊る・Morning・おどれグロッケンシュピール）。フォルダの ID は引き継ぎ（AI会社/引き継ぎ/制作部_イベント3選リール）に書いてある。リポジトリにはファイルの ID も書かない。
  - 落とし方：Drive の連携で `parentId = '<フォルダID>'` を検索してファイルの id を得て、スクラッチに
    `curl -sSL -o bgm.mp3 "https://drive.usercontent.google.com/download?id=<id>&export=download&confirm=t"`
    （フォルダは代表が「リンクを知っている全員が閲覧可」にした。10/17）。
  - 曲はリポジトリにも公開の場所にも置かない。作業が終わったらスクラッチから消す。
- できたら何コマか切り出して自分の目で確かめる（文字のはみ出し・誤字・注記・顔）。

台本.json：

```json
{
  "date": "10/31(土)・11/1(日)",
  "scenes": [
    {"clip": "1.mp4", "name": "ダイナソーフェス", "date": "10/31(土) 13:30〜15:30",
     "place": "勝山市 かつやま恐竜の森", "point": "恐竜クイズなどのスタンプラリー・参加無料"},
    {"clip": "2.mp4", "name": "あの海の見える、路地マルシェ", "date": "10/31(土) 10:00〜16:00",
     "place": "小浜市 阿納", "point": "阿納の民宿の名物料理が味わえる", "start": 1.5},
    {"clip": "3.mp4", "name": "永平寺町 食の体験ツアー", "date": "11/1(日) 10:00〜15:00",
     "place": "永平寺町 道の駅 禅の里", "point": "葉っぱ寿司・きりたんぽなど 各500円"}
  ]
}
```

**Claude Code の編集でできること**：テロップ・注記を入れる、使う5秒を選ぶ（尺を切る）、縦長 720×1280 に切りそろえる、つなぐ、はじめ・おわりの画面、BGM（音量・フェード）、元の音を消す、速さを変える、明るさ・色を少し整える、一部をぼかす、静止画をゆっくり寄る動画にする。
**できないこと**：絵や動きを新しく作る（AI の生成は代表の Gemini・Vids で）、写っている人や物を消す・差し替える、手作業での細かい合成、Gemini・Vids の画面の操作。

### 5. 見せる（代表の OK）
- 確認ページを Artifact で作る（動画2本は `files` で別ファイルにする。1ページ 16MB まで）。Threads の本文・返信（出典）・Instagram のキャプションも同じページに載せる。
- リンクを統括に送る（何を・なぜ・お金）。代表がこのチャットにいるときは、ここでも見せる。
- 直しが出たら、その場面だけ代表に作り直してもらうか、編集で直して、同じページを差し替える。

### 6. キャプション（①②③で行を分ける形。代表が「A」を選んだ）
- Threads（posts/queue.jsonl。`video_url` と、返信 `thread` に出典元のリンク）：

```
来週末 10/31(土)・11/1(日) の福井おでかけ3選🍂

① ダイナソーフェス
10/31(土) 13:30〜15:30／勝山市 かつやま恐竜の森
恐竜クイズなどのスタンプラリー。参加無料

② …

③ …

※画像はイメージです。日時・内容は公式の情報をご確認ください。
```

  返信：`出典元：\n<名前> <公式URL>\n…`
- Instagram（posts/ig-queue.jsonl の `caption`）：本文は同じで、「※画像は…」の前に「くわしくはプロフィールのリンクから」、最後にハッシュタグ（#福井 #福井イベント #福井おでかけ #ふくいおでかけ ＋イベント・地域のもの）。

### 7. 渡す・出す
- 代表の OK が出たら、動画2本を `docs/reel/<対象の土曜の日付>.mp4`（Threads 用）と `docs/reel/<日付>-ig.mp4`（Instagram 用）として入れるブランチを作り、PR を出す。公開 URL は `https://odekake.fukui-fukui.com/reel/<日付>.mp4`。
- おでかけ開発（send_message）に、PR・キャプション2つ・返信（出典）・代表の OK の言葉を送る。おでかけ開発がマージして、queue.jsonl と ig-queue.jsonl に土曜 16:00 で入れる（note に代表の OK の言葉）。
- 出たら統括に投稿の URL を報告し、下の「記録」と引き継ぎ（AI会社/引き継ぎ）を最新にする。
