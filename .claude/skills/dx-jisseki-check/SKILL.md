# 実績報告・申請書のチェック（デジタル支援事務局）

事業者の申請書・実績報告には企業情報や口座情報が入っている。**公開リポジトリや外部サービスに置かない**。このスキルには手順と判断のルールだけを書き、事業者のデータは Google ドライブにだけ置く。

## 置き場所（Google ドライブ「00_デジタル支援事務局」）

元のデータと AI で作った資料は**混ぜない**（代表 11/19）。2つの補助金で同じ形。

```
01_ふくいDX加速化補助金／02_ふくいデジタル導入チャレンジ補助金
├ 01_要領・様式        … 県の要領・マニュアル・様式（元のデータだけ）
├ 02_マニュアル         … 事務局運営マニュアル（元のデータだけ）
├ 03_事業者提出書類     … 元のデータだけ
│  ├ _申請書類          … 申請書（チャレンジは月ごとのフォルダ）
│  ├ 実績提出／番号_事業者名／提出書類 … 実績報告で届いた書類
│  ├ _審査結果・交付決定 … 審査結果、交付決定通知書の zip（DX）
│  └ 【採択】申請書提出  … 採択21社の交付申請書（DX）
└ 90_AI作成資料         … AI で作ったものだけ
   ├ 01_チェックシート（事業者別）／番号_事業者名
   ├ 02_チェックシートひな形・進捗管理
   ├ 03_手順書・テキスト版
   └ 99_作業用スクリプト
90_AI作成資料（共通）   … 資料の場所一覧、引き継ぎ文書
99_受け取った原本       … 受け取ったまま。触らない
```

- チャットで送られたファイルは、03_事業者提出書類 の該当フォルダに入れる（ファイル名は「1-1_システム構築費_本見積書（会社名）」のように番号と中身）。
- ファイルは削除しない。整理はコピーしてから移す。代表がアップロードしたフォルダは名前を変えられないことがある（権限）。そのときはそのままにする。
- 終わったら「00_資料の場所一覧」のメモに1行足す。

## チェックの流れ（DX 実績報告）

1. **届いた書類を全部読む**。PDF は pymupdf で文字を取り、文字がない（スキャン）ものは画像にして目で見る。
   - **Word の表は、同じ値のセルをまとめて読まない**（予算額＝決算額のとき「決算額0」に見えた失敗がある）。セルを1つずつ読む。
2. **照らす資料**をそろえる。
   - 交付決定通知書：03_事業者提出書類／_審査結果・交付決定／交付決定通知書_21社.zip（「2103-番号」が事業者ごと）。交付決定日・号・補助金の額を必ずここで確かめる（事業者の記載はよく違う）。
   - 交付申請書（様式第2）と事業実施計画書（別紙2）：【採択】申請書提出 の事業者フォルダ。事業名・経費明細表（9）・KPI（5）・実施期間。
   - 補助率（小規模2/3・中小1/2）：受付台帳。
3. **チェックシートを作る**：90_AI作成資料／01_チェックシート（事業者別） に事業者フォルダを作り、いちばん新しい事業者別チェックシートを Drive でコピーして中身を書き換える（書式・黄色の条件付き書式・補正依頼の「記載ページ」列をそのまま引き継げる）。
   - シート：チェックシート（確認項目 1-1〜7-7）／支出別チェック（別紙3の1行＝1行、書類欄は ○／×／－）／補正依頼（下書き）。
4. **補正依頼書（送付用）**を Word で作り、Google ドキュメントにして同じフォルダに置く。代表が除く項目を言ったら外す。
5. **メール文**を作る（下の決まり）。

## 判断のルール（代表と決めたこと）

### 書き方
- 「指摘」ではなく「**確認**」と書く。結果欄で「確認」にしたセルは**黄色**（条件付き書式）。
- チェックシートに「**代表**」と書かない。確認者は「**事務局**」。
- 重さは【高】【中】【低】をメモの先頭に付ける。

### 金額
- 様式第8・別紙2・別紙3 は**すべて税抜**。
- 補助金の額＝補助対象経費×補助率、千円未満切捨て、交付決定額以内。
- **別紙2（収支決算書）の予算額**は、交付申請書の別紙2「9 経費明細表」の **A（税抜）** を書く（B＝補助対象経費ではない）。
- **機械装置費・システム費は単価で「50万円以上」「50万円未満」に分けて書く**（別紙2も別紙3の経費区分も）。単価50万円未満の設置調整費・保守・ソフトなどを50万円以上の行にまとめていたら確認。予算額は申請書のまま、決算額を単価で分け、差引増減額を書く。
- 値引きは申請書と同じ扱いなら可。
- 対象外経費の論点（汎用品・保守など）は、**申請時の経費明細と同じなら OK**（50万円の区分は除く）。

### 証拠書類
- **税込200万円以上は契約書が必要**（注文請書・申込書だけなら確認）。外注・委託は金額にかかわらず契約書。「注文請書では不可」とまでは書かない（県が判断する）。
- 税込200万円以上は検査調書も必要（事業者が作る）。検収書だけでは足りない。
- 納品書に検収日・検収者がわかること（交付事務マニュアル 3（4））。
- 単価50万円以上は取得財産管理台帳。
- 相見積：税込10万円以上は2社以上、安い方に発注。発注は見積（相見積を含む）の有効期間内。
- 支払：口座振込。振込手数料・消費税は対象外。振込の「承認・受付済み」画面だけなら、実施を確認できる資料を確認（代表が「添付あり」と言えば OK）。補助対象外の請求と合算した振込は、県に確認する項目として残す。
- 写真：物品の全体写真と、補助金表示（テプラ等）の拡大写真。

### 期限・日付
- 事業完了日＝最後の支払日。実績報告は完了から10日以内。期限を過ぎていても、受け付けるかは県の判断（補正依頼には書かない）。
- 外注先は県外の企業でも可（特定の業者なら選定理由書）。

### KPI
- 実績報告の時点で確定している最新の数値を、どの時点の値か明記して書いてもらう。見込み値は「見込み」と算定の考え方を添えて可。
- 目標に届かなくても、理由と今後の見通しが書いてあれば OK。要領上、目標未達だけで減額・返還する規定はない（額の確定は県）。

### 記載ページ（補正依頼の根拠欄）
- 列名は「**記載ページ**」。資料名は略称で書き、表の外に正式名称とファイル名を注記する。
  - 説明資料：『ふくいＤＸ加速化補助金』採択者向け説明資料（令和８年度）／01_採択者向け説明資料.pdf
  - 支出管理：ふくいＤＸ加速化補助金 補助対象経費の支出管理について／02_補助対象経費の支出管理について.pdf
  - 交付要領：ふくいＤＸ加速化補助金交付要領／03_ふくいDX加速化補助金交付要領.pdf
  - 交付事務マニュアル：令和８年度 ふくいＤＸ加速化補助金 交付事務マニュアル／04_交付事務マニュアル.pdf
- 交付事務マニュアルはページではなく**章・項の番号**で書く（例：3（4）＝「3 補助事業実施にあたっての注意事項」の「（4）物件の取得時の注意」）。
- ページは元の PDF を開いて確かめる（ひな形の根拠欄はずれていることがある）。主なもの：見積の有効期間内の発注＝説明資料 p.10・支出管理 p.2／契約書・検査調書＝支出管理 p.2・p.7・説明資料 p.13／取得財産管理台帳＝支出管理 p.7／テプラ・写真＝支出管理 p.6・p.7／振込の証明＝支出管理 p.3。

## 補正依頼書・メールの決まり

- 補正依頼書：宛名（会社名・代表者）、差出人は事務局、対象の事業名と交付決定（日付・号）、表（No／内容／該当書類／参照（記載ページ））、提出方法、参照資料の正式名称、事務局の連絡先。**提出期限は書かない**。右上の日付は空けておく。
- メール文：補正依頼書を添付したことと、**提出された書類を確認したうえで、追加で修正をお願いする場合がある**ことを書く。事務局のアドレスから送るときは Gmail の下書きにはできない。

## 問い合わせへの回答

- できるだけ簡潔に。わからないところは代表に聞く。
- 実績報告は、不足があれば提出後に追加・修正してもらう流れ。「必要事項を書いて、まず期限までに出してもらう」形で答える。
- 来年度のことは決まっていないと答え、具体的な相談は募集開始後に。審査会が判断することは「何とも言えない」と答える。
- ECサイトの改修などは対象外。既存システムへの機能追加は対象にならない可能性が高い（審査会で判断）。

## チャレンジ補助金（申請書・実績報告）の注意
- 申請書：様式第1・別紙1〜4、税務署発行の納税証明書（法人税・消費税、申請日前1か月以内）、見積書。県税の納税証明書は税務署のものの代わりにならない。
- ツールはデジタルツールカタログに載っているものに限る。
- クラウド使用料は「2/28までの支払額」と「1/31までの利用期間の按分額」の低い方。
- 導入関連費（役務・オプション）に交通費が入っていても、要項に対象外の記載はない（導入作業に伴うものなら可、判断は県）。
- 実績報告の「完了日」の定義は要項にない。DX と同じく最後の支払日と考える案（2/28支払なら3/10まで）だが、県に確認してから答える。
