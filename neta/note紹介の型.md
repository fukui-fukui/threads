# note の紹介投稿の型（2026-11-21 代表 OK）

note 記事を Threads で紹介するときの書き方。参考記事「ドパガキライティング」の要点を、うちの決まりに合わせたもの。
ふつうのイベント・お店の投稿には使わない。作るときは下の型に当てはめ、代表の OK のあと予約に入れる。

## 型

```
（1〜2行目：読む人の困りごとを、読む人の言葉で。事実のように言い切らない）

→（記事の中の答え。何を作った・何ができるか）
① （できること・中身。記事にある事実だけ）
② 
③ 

（記事の中身と値段。無料で読める範囲があれば書く）
（すぐできる小さな行動で終える。例：「まずは無料の部分だけ読んでみてください。」）

（注意書きがあれば ※ で）
```

リンクは返信に「noteはこちら （URL）」で付ける。

## 決まり

- 1行目に正論・説教・あいさつを書かない。困りごと（a）・記事にある意外な事例や数字（b）・逆の発想（c）のどれかで始める。
- 1〜2行目で困りごと、3行目から記事の中の答え。「あなたが悪い」と書かず、やり方・仕組みの問題として書く。
- 1かたまり3行まで。比べるときは ❌⭕️、手順は →、並べるときは ①②③。結論を先に、出し惜しみしない。
- 記事にない数字・出来事・体験は書かない。架空の事例で引き込まない。たとえ話はたとえと分かる形に。
- 煽り・言い切りの言葉（勝ち確・秒で・最強・必ず・ヤバい など）を使わない。値段・口コミには「◯月◯日時点」。
- 自社の記事の紹介には PR を付けない（他社の商品のアフィリエイトなら、本文の最後に空行をはさんで「PR」）。
- 落ち着いた言葉づかい。「〜なんよ」「w」は使わず、絵文字も増やさない。

## 例（2026-11-21 代表 OK。11/11 の PDF ツールの記事）

```
PDFを1つにまとめたいだけなのに、ソフトを入れるのは気が引ける。
仕事のファイルを、ネットのサービスにあげるのも不安。

→ AI（Claude）に一言たのんで、ブラウザで開くだけのHTMLファイルを1つ作りました。
① 結合・分割・並び替え・抜き出し・回転・削除
② インストール不要
③ PDFはどこにも送らず、パソコンの中だけで処理（元のファイルは書き換えない）

AIに送った指示と作り方、完成品のダウンロードをnoteにまとめました。500円で、「はじめに」から第2章までは無料です。
まずは無料の部分だけ読んでみてください。

※動作を確かめたのはChrome系のブラウザです。パスワード付きのPDFは読めません。
```
